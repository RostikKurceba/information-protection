
# Лабораторна робота № 2
## Квадрат Полібія та шифр Гронсфельда

### Мета роботи

Розробити вебзастосунок для шифрування та розшифрування тексту за допомогою квадрата Полібія і шифру Гронсфельда, реалізувати перевірку ключів, роботу з текстовими файлами та автоматизоване тестування.

### Використані технології

- HTML5
- CSS3
- JavaScript (ES Modules)
- Node.js та вбудований модуль `node:test`
- Vite для локального запуску

### Можливості програми

1. Координатне шифрування та розшифрування Полібія.
2. Циклічний зсув символів за рядками квадрата Полібія.
3. Шифрування та розшифрування Гронсфельда.
4. Підтримка українського та латинського алфавітів.
5. Побудова квадрата 6 × 6 за ключовим словом.
6. Завантаження UTF-8 текстових файлів і збереження результатів у TXT.
7. Перевірка ключів і формату координат.
8. Автоматизовані тести.

### Структура проєкту

- `index.html` — структура вебінтерфейсу.
- `css/style.css` — стилі.
- `js/alphabets.js` — алфавіти та побудова квадрата.
- `js/polybius.js` — алгоритми Полібія.
- `js/gronsfeld.js` — алгоритм Гронсфельда.
- `js/file-handler.js` — читання та збереження файлів.
- `js/app.js` — логіка інтерфейсу.
- `tests/cipher.test.js` — автоматизовані тести.

### Встановлення та запуск

Потрібен встановлений Node.js.

Встановіть залежності:

```bash
npm install
```

Запустіть застосунок:

```bash
npm run start
```

Відкрийте адресу, яку виведе Vite, зазвичай `http://localhost:5173/`.

### Запуск тестів

```bash
npm test
```

Тести перевіряють контрольні вектори, зворотність алгоритмів, побудову квадрата, некоректні координати та перевірку цифрового ключа.

### Примітка

Квадрат Полібія містить 36 унікальних символів. Український варіант використовує українські літери та символи `012`, а латинський — латинські літери та цифри `0123456789`.

Програма призначена для навчального дослідження класичних шифрів і не забезпечує сучасного криптографічного захисту даних.
